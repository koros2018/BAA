# BAA 原子函数开发规范

源自 P51（FAIL 910→6）、P57（3 天 58→390 爆发扩展教训）、P75（3 个函数占 FAIL 97.7%）三轮数据。

## 当前约束

- 原子函数容量已满（422 个）。**禁止新增函数数量**；新需求优先走阈值调整、规则参数优化、target_entities 修正。
- 瓶颈不在函数数量，在上游：实体属性抽取完整性、拓扑关系、聚合作用域。改函数前先确认上游信息是否到位。

## 开发检查单

1. **拓扑聚合作用域**：EXIST/DIST 类函数必须显式声明空间上下文（按防火分区/按楼层/按房间聚合），禁止默认按整图聚合。`requires_global_context=True` 的函数在目标实体缺失时应 PASS 而非 FAIL。
2. **双指标验收**：任何判定逻辑改动必须同时报告误报率与漏报率。只报一个指标的验证无效。
3. **统计汇总**：模块必须输出明确的统计汇总（处理数/跳过数/判定分布），便于审计。
4. **YOLO 实体降级**：对 YOLO 来源实体放宽判定（confidence×0.7，跳过精确尺寸/面积判定），且 corridor clear_width <0.5m 等物理不可能的推断直接跳过（DIM-004 教训）。
5. **小构件排除**：疏散门/出口宽度判定排除 <0.8m 小门（DIM-006/DIM-009）。
6. **TEXT 误分类防护**：文字实体匹配构件类型需完整词匹配（如"防火门"），子串匹配会引入大量假 door/fire_door。

## 测试要求

- 每条函数需 PASS/FAIL 双覆盖测试；新增/修改后跑全量：`python -m pytest -q`。
- 真实图纸验证常态化：CI baseline_verify job，6 张固定基线图纸 ±30% 容差。基线变更必须附证据链。

## 断言与错误信息

- 断言信息统一格式：预期值 / 实际值 / 位置坐标。
- 禁止 `pass` 空吞与裸 `except:`；解析失败 → HTTPException(422)，超时 → HTTPException(504)，空结果 → 前端显式提示"未检测到违规"。

## 数据契约

- `analyze()` 只接收原始图元对象；`to_dict()` 仅用于前端/缓存出口，禁止在审查链路中调用（双重序列化会产生 AttributeError: 'dict' object has no attribute 'layer'）。
- 闭包内使用的模块必须在该闭包内独立 import。
