## 一、Villa 误伤修复（核心）

### 问题
Villa 中 3 个真实标准间（9047/9048/9049）被 `grid_pattern` 误伤。

### 根因 1：零宽/零高门洞邻接漏检
- 原 `if dw_v <= 0 or dh_v <= 0: continue` 直接跳过零宽度/零高度门
  （竖直线段/水平线段代表真实门洞），导致 9047/9048 的门
  （DOOR_4655/6241/6313，bbox 宽度 0）检测不到，被误判"无门洞邻接"。
- **修复**：只跳过完全退化门（宽高均为 0），补充零宽/零高门"门线段与
  房间 bbox 相交"判据（无容差，避免 Stadion 看台格间 75mm 外门误判）。
- 位置：[room.py L2104-2110](file:///d:/OpenClawData/BAA/src/baa_engine/semantic_analyzer/room.py#L2104-L2110)、
  [room.py L2132-2154](file:///d:/OpenClawData/BAA/src/baa_engine/semantic_analyzer/room.py#L2132-L2154)

### 根因 2：9049 回折环被 G 门禁抑制
- 扫线法在门洞开口处绕门折返，产生回折环（重复顶点+来回回折，面积比 98.3%），
  是几何噪声而非真实自交。
- **修复**：新增 `_repair_folded_polygon`，仅当每个折返尖刺被"折返线上的门"
  覆盖（真实房间门洞伪影）且修复后简单、面积/bbox 填充 >90% 才保留。
  噪声回折（T 型墙/墙板过提取，尖刺处无门）与真实自交（蝴蝶结，面积比
  0.075-0.75）均不修复。
- 位置：[room.py L2094-2173](file:///d:/OpenClawData/BAA/src/baa_engine/semantic_analyzer/room.py#L2094-L2173)

### 验证结果
- 五图房间数：villa **25**（22+3）/ stadion 50 / dongguan 198 / plans 30 / mosque 0
- 3 个恢复房间均为干净简单多边形：9047（4pts）、9048（4pts）、9049（6pts，修复后）

## 六-B、_split_t_junctions 空间索引优化（追加）

### 定位
`_sweep_line_detect_rooms`（~1392ms）中 `_split_t_junctions` 是主体（1515ms
cProfile）。分段：grid build 318ms + Pass1 query 411ms（cell=100mm）。

### 优化
| 优化 | 说明 |
|------|------|
| `_SpatialGrid.query_bbox` 直接索引 | `_sorted_kx` 与 cells 同步、keys 来自 row.keys() 快照，query 期间只读，键必然存在。去掉 None 检查省 130 万次 dict.get |
| `_split_t_junctions` cell_size 100→300mm | DDA cell 数 ∝ 1/cell_size，build 318→56ms；查询候选超集（18725→21115，+12%），query 411→82ms。T-junction 判据 100mm 不漏检（j 端点距 i<100mm ⟹ j 在 i bbox 扩张 300mm 内），候选超集由 dist>100mm 精确过滤 |
| `insert_segment` dirty 标记 | `_row_keys_dirty` 只需首次插入时设置一次 |

### 效果
- `_split_t_junctions`：1515→323ms（**-79%**）
- `_sweep_line_detect_rooms`：1472→873ms（**-41%**）

## 六-C、_build_relations Phase 5 空间网格优化（追加）

### 定位
`_build_relations`（~1253ms）分段计时：Phase 1 grid build 268ms + Phase 2 165ms
+ Phase 3 66ms + Phase 4 5ms + **Phase 5 202ms**。

### 优化
Phase 5 原为 O(房间×door_wall_map) 全量遍历：door_wall_map 有 2589 个
（dongguan），353 个 room × 2589 = 91.4 万对检查（实测 202ms）。改为对
door_wall_map 的 wall 建 1000mm 网格，room 查询 expand=1（dist<500mm ⟹
轴向间隙<500mm<1000mm ⟹ 必落在对方 cell 的 ±1 邻域，候选为合法对超集）。
输出等价：wall_rooms 是 set，最终按 sorted(wall_rooms.get(host_id)) 排序，
候选顺序不影响结果。

### 效果
- `_build_relations`：1253→1082ms（-14%），累计 2003→1082ms（**-46%**）
