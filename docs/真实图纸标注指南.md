# BAA 真实图纸标注指南

## 1. 概述

本文档指导标注人员为 BAA 项目的真实图纸渲染图进行标注，生成用于 YOLO 领域适配训练（domain adaptation）的标注数据。

**背景**：当前 v6 模型（mAP50=0.572）在合成数据上表现良好，但真实图纸渲染图的信息密度极低（约 0.2% 非白像素），导致推理置信度集中在 0.05-0.20。需要人工标注真实图纸数据，进行领域适配微调。

**标注目标**：为每张渲染图中的建筑图元绘制边界框（bounding box），并标注正确的类别。

---

## 2. 渲染图生成

### 2.1 运行渲染脚本

```bash
# 进入项目根目录
cd /path/to/BAA

# 渲染所有真实图纸
python scripts/render_real_drawings.py

# 指定 DPI（默认 200，保留完整细节）
python scripts/render_real_drawings.py --dpi 300

# 指定输出目录
python scripts/render_real_drawings.py --output-dir data/real_renderings

# 只渲染单张图纸（用于测试）
python scripts/render_real_drawings.py --single "图纸名称.dxf"

# 干运行模式（检查文件列表，不渲染）
python scripts/render_real_drawings.py --dry-run
```

### 2.2 输出结构

```
data/real_renderings/
├── <filename>.jpg       # 渲染后的图像（白底黑线，JPG 格式）
└── labels/
    └── <filename>.txt   # 空白 YOLO 标注文件（等待人工标注）
```

### 2.3 输出信息

渲染脚本会输出每张图的以下信息，用于评估标注难度：
- **图像尺寸**（像素宽×高）
- **文件大小**（KB）
- **非白像素占比**（%）：信息密度指标，越低说明图纸越稀疏
- **渲染耗时**（秒）

## 3. 推荐标注工具

### 方案一：labelImg（推荐）

**优点**：轻量、专为 YOLO 标注设计、支持自动保存

**安装**：
```bash
cd /path/to/BAA
source venv/bin/activate
pip install labelImg pyqt5
```

**启动**：
```bash
source venv/bin/activate
labelImg data/real_renderings/ data/real_renderings/labels/classes.txt
```

**配置**：
1. 标注格式选择 **YOLO**
2. 自动保存模式：开启（View → Auto Save Mode）
3. 显示标签：开启（View → Display Labels）
4. 快捷键：
   - `W`：创建矩形框
   - `D`：下一张图
   - `A`：上一张图
   - `Ctrl+S`：保存
   - `Del`：删除选中框

### 方案二：CVAT（Web 标注平台）

**优点**：多人协作、自动标注辅助、Web 界面

**安装**（Docker）：
```bash
docker run -p 8080:8080 cvat/server
```

**导出**：标注完成后导出为 YOLO 格式，然后复制到 `data/real_renderings/labels/` 目录。

### 方案三：Ultralytics YOLOv8 预测 + 手工修正

**适用场景**：利用现有模型生成初始标注，人工修正

**流程**：
1. 用现有模型推理：
   ```python
   from ultralytics import YOLO
   model = YOLO("runs/detect/.../best.pt")
   model.predict("data/real_renderings/", save_txt=True)
   ```
2. 将预测结果复制到 `data/real_renderings/labels/` 目录
3. 使用 labelImg 逐张修正

## 4. 18 个类别的标注要点

### 4.1 建筑结构类

| 类别 | 视觉识别提示 | 标注范围 |
|------|-------------|---------|
| **wall** (0) | 连续的粗实线，构成房间/空间的分隔边界。注意区分墙体与尺寸线（尺寸线有箭头）。 | 沿墙体中心线绘制矩形框，覆盖整个墙段 |
| **door** (1) | 门符号：通常为四分之一圆弧+直线，或矩形+直线。在墙线上开口处。 | 覆盖门洞范围（含门扇），紧贴墙体 |
| **window** (2) | 窗符号：三条平行线（或两条线+中间虚线），在墙线上开口处。 | 覆盖窗洞范围（含窗框），紧贴墙体 |
| **fire_window** (9) | 防火窗：与普通窗类似，但标注文字含"FC"或"防火窗"。 | 同 window，覆盖窗洞范围 |
| **staircase** (3) | 楼梯符号：连续折线（台阶）+ 箭头（上/下方向）。常见于楼梯间区域。 | 覆盖整个楼梯区域（含休息平台） |
| **corridor** (4) | 走廊：狭长的空间，两侧有房间门。通常标注"走道"或"走廊"文字。 | 覆盖走廊的完整区域（从入口到端头） |
| **shaft** (10) | 管井/竖井：小方块或小矩形，通常标注"风井"、"电井"、"管井"等。 | 覆盖井道的外边界 |

### 4.2 消防设施类

| 类别 | 视觉识别提示 | 标注范围 |
|------|-------------|---------|
| **fire_door** (5) | 防火门：与普通门类似，但标注文字含"FM"、"甲"、"乙"、"丙"级。门扇上可能有"防火门"字样。 | 覆盖门洞范围，紧贴墙体 |
| **exit** (6) | 安全出口：通常标注"安全出口"文字，或"出口"箭头。常见于楼梯间门口。 | 覆盖出口门洞或出口标识区域 |
| **fire_lane** (7) | 消防车道：图纸中标注"消防车道"或"消防车通道"的宽大路径。通常标注在建筑外围。 | 覆盖车道宽度的完整区域 |
| **fire_zone** (8) | 防火分区：用双线或虚线围合的区域，标注"防火分区"或"FZ-XXX"。通常在分区边界线处。 | 覆盖整个防火分区的面积区域 |
| **exit_sign** (12) | 疏散指示标志：小矩形图标，带箭头方向。通常标注在走廊墙面或门上方。 | 覆盖标志图标本身 |
| **sprinkler_system** (13) | 喷淋系统：图纸中标注"喷淋"、"SP"或"ZP"的管线/设备。常见于天花板平面图。 | 覆盖喷淋立管或系统区域 |
| **fire_alarm** (14) | 火灾报警：图纸中标注"烟感"、"温感"、"手报"或"FAS"的设备符号。 | 覆盖设备图标范围 |
| **evacuation_lighting** (16) | 疏散照明：标注"应急灯"、"疏散灯"或"EL"的设备符号。 | 覆盖灯具图标范围 |
| **refuge_floor** (17) | 避难层/避难间：标注"避难"或"RF"的区域。通常在高楼层或屋顶。 | 覆盖避难区域范围 |

### 4.3 其他类

| 类别 | 视觉识别提示 | 标注范围 |
|------|-------------|---------|
| **room** (11) | 房间：由墙体围合的封闭空间，通常有文字标注房间名称（如"办公室"、"机房"）。 | 覆盖房间的完整封闭区域（含墙体厚度） |
| **insulation** (15) | 保温/隔热层：图纸中标注"保温"、"隔热"或"INS"的填充区域。通常在外墙或屋顶。 | 覆盖保温层区域 |

### 4.4 标注注意事项

1. **边界框紧贴目标**：不要留过多空白，也不要切掉目标边缘
2. **重叠处理**：如果两个目标重叠（如门在墙上），两者都要标注，不要省略
3. **小目标**：即使目标很小（如烟感探测器），也要标注
4. **模糊情况**：如果不确定类别，优先标注为最接近的类别，在备注中说明
5. **遗漏**：如果图上明显有目标但未被标注，一定补上

## 5. 标注文件格式说明

### 5.1 YOLO 格式

每个 `.txt` 文件对应一张渲染图，每行标注一个目标：

```
<class_id> <x_center> <y_center> <width> <height>
```

**参数说明**：
- `class_id`：类别索引（0-17，见下方类别映射表）
- `x_center, y_center`：边界框中心的归一化坐标（值域 0~1）
- `width, height`：边界框宽高的归一化值（值域 0~1）

**归一化公式**：
```
x_center = bbox_x_center / image_width
y_center = bbox_y_center / image_height
width = bbox_width / image_width
height = bbox_height / image_height
```

### 5.2 类别映射文件

在 `data/real_renderings/labels/classes.txt` 中写入（labelImg 需要此文件）：

```
wall
door
window
staircase
corridor
fire_door
exit
fire_lane
fire_zone
fire_window
shaft
room
exit_sign
sprinkler_system
fire_alarm
insulation
evacuation_lighting
refuge_floor
```

### 5.3 示例

```
0 0.500 0.500 0.200 0.800    # wall
1 0.600 0.500 0.050 0.100    # door
11 0.300 0.400 0.150 0.150   # room
```

## 6. 标注完成后的验证流程

### 6.1 自动验证脚本

运行 `scripts/validate_real_drawings.py`（如果存在）或以下检查：

```bash
# 检查标注文件是否为空（未标注的应该是 0 字节或空文件）
find data/real_renderings/labels/ -name "*.txt" -empty

# 检查标注文件数量是否与渲染图数量一致
ls data/real_renderings/*.jpg | wc -l
ls data/real_renderings/labels/*.txt | wc -l

# 统计各类别数量
cd /path/to/BAA
python3 -c "
from pathlib import Path
labels_dir = Path('data/real_renderings/labels')
from collections import Counter
class_counts = Counter()
for f in sorted(labels_dir.glob('*.txt')):
    for line in open(f):
        line = line.strip()
        if line and not line.startswith('#'):
            cls = int(line.split()[0])
            class_counts[cls] += 1
print('类别统计:')
YOLO_CLASSES = ['wall','door','window','staircase','corridor','fire_door','exit','fire_lane','fire_zone','fire_window','shaft','room','exit_sign','sprinkler_system','fire_alarm','insulation','evacuation_lighting','refuge_floor']
for cls_id in sorted(class_counts):
    print(f'  {cls_id}: {YOLO_CLASSES[cls_id]} = {class_counts[cls_id]}')
print(f'总标注数: {sum(class_counts.values())}')
print(f'标注文件数: {len(list(labels_dir.glob(\"*.txt\")))}')
"
```

### 6.2 可视化检查

```bash
# 使用 YOLO 的可视化功能检查标注是否正确
cd /path/to/BAA
python3 -c "
from ultralytics import YOLO
import cv2
import os
from pathlib import Path

renderings_dir = Path('data/real_renderings')
output_dir = Path('data/real_renderings_checked')
output_dir.mkdir(exist_ok=True)

for img_path in sorted(renderings_dir.glob('*.jpg')):
    # 读取图像和标注
    img = cv2.imread(str(img_path))
    h, w = img.shape[:2]
    label_path = renderings_dir / 'labels' / f'{img_path.stem}.txt'
    if label_path.exists():
        for line in open(label_path):
            parts = line.strip().split()
            if len(parts) == 5:
                cls, xc, yc, bw, bh = map(float, parts)
                x1 = int((xc - bw/2) * w)
                y1 = int((yc - bh/2) * h)
                x2 = int((xc + bw/2) * w)
                y2 = int((yc + bh/2) * h)
                cv2.rectangle(img, (x1, y1), (x2, y2), (0, 255, 0), 2)
    cv2.imwrite(str(output_dir / img_path.name), img)
print(f'可视化结果保存在: {output_dir}')
"
```

### 6.3 人工抽查

1. 随机选取 20% 的标注文件进行人工复查

   - 边界框是否紧贴目标
   - 类别是否正确

## 7. 标注量建议

### 7.1 初始阶段

| 阶段 | 标注量 | 目的 |
|------|--------|------|
| 第一批 | **20 张** | 覆盖多种图纸类型（建筑平面、消防、电气、暖通等），作为初始训练集 |
| 第二批 | 30-50 张 | 补充覆盖不足的类别和图纸类型 |
| 第三批 | 50-100 张 | 根据模型评估结果，针对性补充 |

### 7.2 类别覆盖目标

初始 20 张应确保：
- 每个类别至少有 **3-5 个** 标注实例
- 覆盖至少 **3 种不同** 的图纸类型
- 包含大图（>2000px）和小图（<1000px）

### 7.3 质量要求

- 标注框与目标边缘的误差 < 5 像素
- 类别准确率 > 95%
- 无遗漏目标（明显可见的图元必须标注）

## 8. 数据整合

标注完成后，运行 `scripts/merge_real_annotations.py` 将数据整合到 YOLO 训练格式：

```bash
python scripts/merge_real_annotations.py
```

该脚本会：
1. 读取 `data/real_renderings/labels/` 下的标注
2. 按 80/20 划分训练集/验证集
3. 复制到 `data/real_train/` 目录
4. 生成 `data/real_train/data.yaml`
