一、背景与根因

P121-V 视图级过滤已将非平面子区整体判为非 plan 并跳过，但 Stadion 的 y∈[33k, 37k] 看台踏步区仍被判为 plan（有足够平面证据）， 扫线法在此区域内切出 11 个 4000×3100mm 同质矩形，全部进入审查清单。

根因：原有 A/B/C/D/E/F/G 门禁分别处理退化多边形、未闭合边界、重复实体、 容器房间、空壳面、贴图框等几何异常。对于同质周期性栅格 （看台座位格、货架格、图例表格单元），每个成员单独过各门禁时均无明显异常——面积在合理范围、 无门洞邻接、无文字标注——因此全部通过，产出一堆无建筑语义的假房间。

二、结构判据设计（六重检验）

新增函数 _detect_grid_pattern_suppressions()（room.py L1802-1962）， 仅针对 sweep 派生房间（line_chain_* ID 前缀），显式分类的闭合多段线房间不参与检测。

九、Villa 误伤修复（2026-11-10 追加）

已解决：Villa 3 个真实标准间（9047/9048/9049）误伤已修复，五图房间数 villa 25（22+3）/ stadion 46 / dongguan 186 / plans 30 / mosque 0，全部回到基线+误伤恢复。

根因修复
门洞邻接判据漏检零宽/零高门：原 if dw_v <= 0 or dh_v <= 0: continue 跳过零宽度/零高度门（竖直线段/水平线段代表真实门洞），9047/9048 的门 （DOOR_4655/6241/6313，bbox 宽度 0）检测不到，被误判"无门洞邻接"。 只跳过完全退化的门（宽高均为 0）；补充零宽/零高门"门线段与房间 bbox 相交" 判据（无容差，避免 Stadion 看台格间 75mm 外门误判）。
9049 回折环被 G 门禁抑制：扫线法在门洞开口处绕门折返，产生回折环 （重复顶点+来回回折，面积比 98.3%），是几何噪声而非真实自交。 新增 _repair_folded_polygon：仅当每个折返尖刺都被「折返线上的门」 覆盖（真实房间门洞伪影）且修复后简单、面积/bbox 填充 >90% 才保留。 噪声回折（T 型墙/墙板过提取，尖刺处无门）与真实自交（蝴蝶结，面积比 0.075-0.75）均不修复。
