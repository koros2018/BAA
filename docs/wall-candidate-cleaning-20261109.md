# 墙线候选清洗复测（2026-11-09，单位归一化后）

> 本文取代 §19.3 的「碎片率不可达」证据基础，但**不改变其结论**：面提取前置仍不可行。
> 原因是新证据指向另一个根因（碎片面 98.9% 是双线墙空腔），不是候选未清洗。
> §19.3 原文保留，只在文末追加指向本文的标注。

## 1. 本轮要回答的问题

§19.3 判「墙线候选清洗前置不可行」，其三条否决理由都基于**归一化前**的测量
（stadion/plans/demo 墙线候选 = 0）。归一化已落地（§20），本轮按同一口径重测：

1. 5 张图的墙线候选现在的几何画像是什么？
2. 轴网 / 图例 / 家具 / 场地线能否用几何特征稳定识别？
3. 清洗后碎片率能否 <20%（止损线 40%）？房间候选面是否被保住？

## 2. 方法（临时探针，已删除）

- 取数与生产一致：`DrawingParser.parse` → `_collect_wall_lines` →
  `_exclude_table_and_frame_prims` → `_collect_wall_segments` → `_axis_align_merge`。
- 画像指标：长度分箱、近轴占比、端点 100mm 聚类连通性、5m 网格密度、
  长直线+等距平行（轴网签名）、密集短线段（图例签名）。
- 剥面指标：`_split_t_junctions` → 平面图 → 左手定则面遍历 → 正向面。
  碎片 = 面积 <0.5㎡ 的正向面；**墙腔** = 短边 ≤600mm（双线墙厚度带）；
  有效碎片 = 非墙腔碎片 / 全面数。
- 门洞分隔率：门洞 bbox 中心沿短边方向 ±(短边/2+400mm) 落点，命中两个不同 ≥5㎡ 面即记分隔。
- 重复面：正向面质心按 300mm 网格去重。

## 5. 结论

### 5.1 碎片率的 59.4% 是度量口径造成的，不是墙线网络不可用

东莞通 6,266 个碎片面里 6,199 个（98.9%）是双线墙空腔：短边中位数 300mm，
即两道墙线之间的墙厚空腔。这些面**本来就进不了房间候选**——
`_sweep_and_filter` 的短边门槛是 2000mm，墙腔在房间判定前已被剔除。
按「排除墙腔后的有效碎片率」计，5 张图分别是 0.63% / 0.73% / 0.27% / 0% / 无面，
全部远低于 20% 目标。

因此 §19.3 的止损门槛（碎片率 <20%）在本轮口径下**已达成**；
但这不是靠清洗达成的，而是因为原口径把墙厚空腔算成了碎片。

### 5.2 清洗本身要么无效，要么破坏房间

- **轴网 / 图例 / 家具清洗无效**：轴网签名 5/5 为否；小簇清洗在东莞通只把碎片率
  59.38% → 53.72%（−5.7pt，仍 >40% 止损线），房间候选面 767 → 775、面积基本不变。
  也就是说，清洗掉的不是碎片来源。
- **双线墙配对删线“有效但危险”**：东莞通 6.99%、villa/stadion 0%，且东莞通房间候选
  767 → 848、面积 −2.2%。但 plans 从 8 个房间面塌成 1 个（面积 227.6 → 105.9㎡）——
  低密度图里每条墙线都是房间边界，删掉一侧等于拆掉内墙。
  **该规则不能作为生产规则上线**，即使它在多数图上能把数字打到目标以内。
- **独立小簇清洗也不安全**：plans 删掉 223/320 段后房间面 8 → 4；
  villa 恰好相反（135 → 143）。同一规则在不同图上效果相反，说明它没有可判别语义。

### 5.3 剩下真正的质量问题

| 指标 | 东莞通 baseline | 目标 | 判读 |
|---|---|---|---|
| 重复面比例 | 31.0% | 越低越好 | 真实存在：重合墙线产生嵌套/重复面 |
| 门洞分隔率 | 6.9% | >60% | 真实缺口：门洞仍未把两面分开 |
| 悬空端点率 | 12.7%（villa 20.1%、stadion 55.8%） | 越低越好 | 洞口/柱/楼梯挡墙处断开 |

这三项才是面提取质量的真问题；它们与「候选清洗」不是同一类工作。

## 6. 建议（需产品口径拍板）

1. **修改碎片率口径**（文档 + 验收脚本）：只统计非墙腔碎片，或在验收里同时给出
   「全部碎片率 / 有效碎片率」双口径。本轮数据表明单看 59.4% 会误导路线判断。
2. **不要把候选清洗上线**：五张图里没有一张能靠几何清洗稳定达标，
   强行上线只会在低密度图（plans 这类真实住宅平面）上拆掉房间。
3. 下一轮若继续几何路线，优先级应为：
   ① 重复面去重（31%）；② 门洞成对落点切开墙段（分隔率 6.9%）；
   ③ 双线墙→中心线重建（拓扑保持，而不是删线）——这是唯一可能同时降碎片且保房间的方案，
   但工作量大于清洗，且需要 5 张图的人工房间真值做验收。
