# BAA v5 MVP 边界文档

> **产出日期**：2026-10-27  
> **关联任务**：E1-T6（Roadmap v5 阶段 E1 收尾）  
> **基线版本**：v2.5.80-stable / 分支 `semantic-analyzer-layer-sharding-JM65bP`

---

## 1. 定位一句话

> BAA 是面向中小型民营设计院的消防合规智能审图工具——以 DXF/CAD 原生解析为核心，自动检出消防疏散违规，一键生成审查报告。

**不做**：通用 BIM 审图、DWG 编辑、YOLO 视觉推理（默认关闭）、iOS/钉钉原生 App、自建支付网关。

### 2.2 明确不做（v5 坚守）

| 不做项 | 理由 |
|--------|------|
| DWG 格式支持（ODA SDK） | 付费信号明确后再评估，ODAcad 授权成本高 |
| YOLOv8 视觉推理（生产路径） | P84 确认 mAP≈0，enhancement.py 已 stub 返回空列表；默认 VISION_ENABLED=false |
| IFC/STEP 深化（v5 内） | E3-T4 计划中，需真实项目审计数据验证后再推进 |
| PostgreSQL 迁移（v5 内） | E2-T1 计划，SQLite 满足单机部署需求，PG 延后 |
| 前端组件单测（v5 内） | E2-T5 计划，先用 E2E 兜底，待 vitest+jsdom 环境就绪再补 |
| 天正 T3 原生识别 | E2-T6 计划，pywin32/AutoLISP 前置条件依赖 Windows 环境 |
| 多副本水平扩展 | E3-T2 计划，RBAC + Redis 锁前置 |
| iOS / 钉钉原生 App | 企业微信渠道已覆盖；原生 App 开发成本远高于收益 |
| 自研支付网关 | 用 Stripe + 微信支付；不重复造轮子 |
| YOLOv11 迁移 / GNN / VLM | 商业验证前不投入新模型路线 |
| 新增原子函数 | 引擎容量已满（85+），走阈值/规则调优 |

## 3. 目标客户

### 3.1 第一目标：中小型民营设计院（50–200人）

| 维度 | 特征 |
|------|------|
| 痛点 | 审图周期长（平均 3–5 轮修改），人工合规检查易漏项 |
| 触发场景 | 出现重大审图事故 / 主管部门检查不合格 / 投标需要数字化证明 |
| 决策链 | 总工（技术评估）→ 院长（预算审批）→ IT（部署对接） |
| 价格敏感度 | ¥2,000–5,000/月舒适区，超过 ¥10,000/月需显著 ROI 证明 |
| 部署偏好 | 优先 SaaS，数据安全要求高的客户接受私有部署 |

### 3.2 第二目标：审图单位（施工图审查机构）

| 维度 | 特征 |
|------|------|
| 痛点 | "量增人减"压力，人工审图效率瓶颈 |
| 刚性需求 | 高，政策驱动数字化审图 |
| 壁垒 | 需要地方住建局关系或资质背书 |
| 付费意愿 | 高（¥2万/年/机构），但决策周期 3–6 个月 |

### 3.3 暂不主攻

| 客户类型 | 原因 |
|----------|------|
| 大型国有设计院 | 自有审图体系，替换成本高，SaaS 不可行，必须私有部署 |
| 施工单位 | 对设计类工具付费意愿低（市场专家评估修正后 ARPU ¥3万/年） |
| 住建局/政府部门 | 采购流程长，需招投标，非 MVP 切入点 |

## 4. 定价锚点

| 版本 | 定价 | 功能 | 目标客户 |
|------|------|------|----------|
| **体验版** | 免费 | 3 个项目/月，基础审图（National 标准） | 个人工程师 / 小团队试用 |
| **专业版** | ¥299/月（年付 ¥2,999） | 无限项目，National + Local 标准切换，整改通知单 Word 导出 | 小型设计院（50人以下） |
| **企业版** | ¥999/月（年付 ¥9,999） | 多用户协作，企业自定义报告模板，API 接入，SOP 客户成功流程 | 中型设计院（50–200人） |
| **私有部署** | 议价（¥5万–20万/年起） | 完全私有，数据自主，定制规范库，技术支持 SLA | 审图单位 / 大型设计院 / 住建局 |

**定价策略说明：**
- 体验版限流（3 项目/月）防止滥用，同时作为获客漏斗
- 专业版锚定中小设计院的 IT 月预算（约 ¥500–2,000/月）
- 企业版包含协作和 API，瞄准有集成需求的设计院
- 私有部署按规模议价，首单目标 ¥5万+/年
