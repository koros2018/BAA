## 二、定价（草案）

### 2.1 免费版
- **价格**：永久免费
- **License**：无需 License，注册即使用
- **限制**：月审查量 5 张，超标后只读不阻塞（历史数据保留）

### 2.2 专业版
- **价格**：¥299 / 账号 / 月
- **License**：按需购买（最小 1 账号），支持按月/按年（年付享 8 折）
- **包含**：50 张/月审查量 + 全部内置标准集 + 离线导出 + 客户成功支持

### 2.3 企业版
- **价格**：年框协商
  - SaaS 模式：¥2,999 / 月起（含 50 账号 + 不限审查量）
  - 私有化部署：一次性授权 ¥50,000 起 + 年服务费 ¥15,000
- **License**：RSA 签名 License 文件，绑定企业主体
- **包含**：全部能力 + 驻场支持 + 定制标准集开发

### 2.4 试用策略
- 首次创建 API Key 自动激活 **14 天专业版试用**
- 试用期间享有专业版全部权益
- 试用到期未续费 → 自动降级为免费版（数据保留 90 天）

## 三、SLA 承诺

### 3.1 可用性

| 版本 | SLA | 计算方式 | 违约补偿 |
|------|-----|---------|---------|
| 专业版 | ≥99.9% | 月度 uptime = (30天×24h − 宕机时间) / 30天×24h | 每低 0.1% 延长 1 个月账期 |
| 企业版 | ≥99.95% | 同上 | 每低 0.05% 延长 1 个月账期 |

**不计入 SLA 的情况**：
- 客户侧网络/硬件故障
- 计划内维护（提前 48h 通知）
- 不可抗力（地震、火灾、战争）

### 3.2 故障响应

| 级别 | 定义 | 响应时间 | 解决目标 |
|------|------|---------|---------|
| P1 致命 | 系统不可用 / 数据丢失 | ≤15min | ≤4h |
| P2 严重 | 核心功能降级（如审查失败） | ≤30min | ≤8h |
| P3 一般 | 非核心功能异常 | ≤2h | ≤3 工作日 |
| P4 咨询 | 功能咨询 / 优化建议 | ≤1 工作日 | 纳入排期 |

### 3.3 数据安全

- 数据加密：传输 TLS 1.3，存储 AES-256
- 备份策略：专业版每日增量 + 每周全量（保留 30 天）；企业版实时双活 + 异地容灾（保留 180 天）
- 数据删除：客户可申请彻底删除（72h 内完成），删除后不可恢复
