## 标注规则

1. **确认违规（CONFIRMED）**：引擎判定正确，该违规应该被检出
2. **无法判定（SKIP）**：引擎判定结果不可靠（连通性分析缺陷/属性缺失），跳过此违规判定
3. **误报（FALSE_POSITIVE）**：引擎判定错误，实际不违规
4. **漏报（FALSE_NEGATIVE）**：引擎未检出但实际存在的违规（当前阶段暂不标注，待人工审查图纸）
