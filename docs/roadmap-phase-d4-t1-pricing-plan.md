## 3. 改造范围

### 3.1 阶段 A：定价表（0.5 天）

**产出**：`docs/pricing-sla.md`

**内容结构**：
```
# BAA 智能审查平台 定价与 SLA

## 一、版本对比表
| 能力 | 免费版 | 专业版 | 企业版 |
|------|--------|--------|--------|
| 标准集范围 | 国标（CN-National-v1） | 国标+地标（CN-Shanghai-v1 等） | 全部自定义 |
| 并发审查数 | 1 | 5 | 20+ |
| 月审查量 | 5 张/月 | 50 张/月 | 不限 |
| 离线导出 | ❌ | ✅ | ✅ |
| 客户成功支持 | 工单 | 专属客户经理 | 驻场支持 |
| SLA 可用性 | — | 99.9% | 99.95% |
| 部署形态 | SaaS | SaaS | SaaS / 私有化 |

## 二、定价（草案）
- 免费版：永久免费，无 License
- 专业版：¥299/账号/月，含 50 张/月审查量
- 企业版：按年协商，SaaS ¥2999/月起，私有化一次性授权 ¥50000 起

## 三、SLA 承诺
- 可用性：专业版 ≥99.9%，企业版 ≥99.95%
- 故障响应：4h（工作时间内）
- 数据备份：每日增量 + 每周全量，保留 30 天

## 四、试用与付费流程
1. 注册 → 自动创建 API Key → 14 天试用（专业版权益）
2. 试用到期 → 降级为免费版（保留历史数据）
3. 续费 → 支付渠道（Stripe/微信）→ License 自动发放 → 功能解锁

## 五、法务预检清单
1. [ ] SaaS 服务条款（ToS）
2. [ ] 隐私政策 + 数据处理协议（DPA）
3. [ ] 许可协议（License Agreement）
4. [ ] 退款政策
5. [ ] 责任限制条款
```
