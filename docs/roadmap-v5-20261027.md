## 2. 阶段 E 规划（E1–E3）

### 阶段 E1（1–2 月）· 引擎精度 + 安全基线

**目标**：G7/G9/G10 属性+拓扑根治，G22/G18 安全合规落地

| 任务 | 内容 | DoD | 依赖 | 状态 |
|------|------|-----|------|------|
| **E1-T1** ✅ | 块语义接入 | v4 T-A2 已完成；东莞通 40 张图纸 未分类率 5.63%→4.78%（-15.1%），block_default 726→438（-39.7%），84 测试全过 | T-C1 | v4 完成，继续收窄需拓扑 |
| **E1-T2** ✅ | 属性抽取补齐 | v4 T-A4 已完成；关键属性缺失率 23.50%→16.33%（M-series 累计 -7.17pp） | T-C1 | v4 完成，剩余缺口待拓扑补齐 |
| **E1-T3** ✅ | NetworkX 显式拓扑 | v4 T-B1 已完成；`topology.py` + `topology_routes.py`，25 测试全过（test_topology + test_topology_api + test_security_tc4） | E1-T1 | v4 完成 |
| **E1-T4** ✅ | 匿名访问生产门禁 | `BAA_ALLOW_ANONYMOUS` 默认 false；空 API_KEYS 时拒绝所有请求（3 测试通过） | D4-T2 | v4 T-C4 完成 |
| **E1-T5** ✅ | AGPL/GPL 隔离 | PyMuPDF 子进程隔离（pdf_service）；YOLOv8 延迟导入+stub（enhancement.py 返回空列表）；VISION_ENABLED 默认 false（T-A1 验收通过） | D4-T2 | v4 T-A1 完成 |
| **E1-T6** ✅ | MVP 边界定稿 | 产出 `docs/mvp-scope-v5.md`：功能范围/目标客户/定价锚点/成功指标 | E1-T1~T5 | 本次完成 |

**验收**：
- 未分类率从 16% → ≤10% ✅（实测 4.78%）
- 属性缺失率从 80% → ≤30% ✅（实测 16.33%）
- 误报率从 93.8% → ≤50%（依赖拓扑作用域，后续监控）
- `pip install baa` 不装 PyMuPDF/YOLOv8 ✅（进程隔离+延迟导入）
- 空 API_KEYS 请求返回 401 ✅
- MVP 边界文档 ✅（docs/mvp-scope-v5.md）
