## 定位校准

BAA = 图纸**合规审查**产品，不是通用图纸理解平台。核心护城河是 422 原子函数 + 199 规范条款 + 审核工作流闭环，不是解析能力本身。解析投入必须服务于审查准确率与客户交付。

## 禁令（沿用 2026-08-17 复盘并强化）

| 禁令 | 原因 |
|------|------|
| 禁止新增原子函数数量 | 422 已足够，瓶颈在上游实体属性与拓扑 |
| 禁止光栅主干路线（YOLO/分割） | 已证伪：矢量语义渲染后不可逆丢失，真实图纸 mAP 断崖 |
| 禁止无真实数据验证的 P 项 | P57 式爆发扩展教训 |
| 禁止在 >1000 行核心文件上继续堆叠 | 先拆后写 |
| 禁止 `pass` 空吞与裸 `except:` | P120 已清零，保持 |
| 禁止块展平丢弃块名/属性 | S1 block_refs 已确立保留语义原则 |
| 禁止未声明依赖 | 可选依赖掩盖潜伏缺陷（DWG 链路 4 缺陷教训） |

## 阶段 A（0-1 月）：验收闭环 + 商业破冰

> 本阶段所有技术投入的唯一判据：是否让 3 个真实项目跑通审查→审核→整改单全流程。

| 序 | 项 | 交付 | 验收 |
|----|-----|------|------|
| A1 | **P135 天正 T3 识别率验收闭环** | 标注集 ≥3 张 T3 图（AutoCAD T3→T0 另存 + 人工标注），墙/门/窗/柱 4 类每张 ≥50 实体；P127 三层降级管线跑基线；差距分析报告 | 墙 F1≥0.80、门窗 F1≥0.75 |
| A2 | **S2 块语义分类** | 块名→构件类型映射表（复用 S1 block_refs 输出）；图例查表基线；与 LAYER_RULES 联合判定 | 东莞通未分类率降 ≥50%；消防设备 EXIST 类误报率下降 |
| A3 | **P113 真实用户试用** | 3-5 个项目包（住宅/办公/数据中心/医院/工业各 1）；黄金标准 v2；误报→feedback_engine 闭环 | ≥3 份审计报告；黄金标准 +100 条；0 无依据新增 FAIL |
| A4 | **P118 商业模式验证** | 1 页定位 + 1 页定价 + 5 客户访谈 | MVP 边界文档（本地部署版/SaaS/审图机构插件三选一） |

**A 阶段出口条件**：A3 完成且 A4 有明确 MVP 定位。若客户访谈否定当前定位，阶段 B/C 重排。

## 明确不做（6 个月内）

- **GNN 拓扑推理 / VLM 端到端 / 数字孪生 3D Tiles** — 商业验证前不投入
- **YOLOv11 迁移** — 降级为消防符号专项研究项，不占主线资源
- **新原子函数** — 容量满，新需求走阈值/规则调优
- **许可证隔离（P134）** — 待私有部署客户明确要求 AGPL 合规时启动

## 迭代纪律

1. 每个 P 项必须真实数据验证；验收指标同时覆盖**误报率与漏报率**
2. 每完成一组功能打 `-stable` 标签，回退路径清晰
3. 依赖变更三同步：requirements.txt + CI 环境 + 跨平台验证清单
4. 真实图纸基线变更必须附证据链（图纸 ID + 根因 + 前后对比），禁止无依据调整
5. 每阶段结束按 [复盘模板](templates/retrospective-template.md) 出复盘报告
