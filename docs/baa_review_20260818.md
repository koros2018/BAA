## 四、关键教训

### ✅ 做对的

1. **噪声治理优先**：P82-P83 把 124 违规降到 0，证明了"先准后多"的策略正确
2. **真实图纸常态化验证**：CI baseline 6/6 张固定图纸，防止核心能力退化
3. **扫线法替代 DFS**：技术选型正确，建筑图覆盖率从不可用→95%+
4. **模块化拆分**：team_collab 1154→3 文件，消除大文件

### ❌ 做错的 / 遗漏的

1. **YOLO 管线断在伪标签**：10 类标签已生成，但模型训练 mAP50=0.001 后无后续 commit，管线未闭环
2. **大图纸性能未系统解决**：84 张 SKIP/超时占 62%，仅靠 SKIP_STRUCT/SKIP_BIG 跳过，不是解决方案
3. **前端零文件**：`find` 检出 0 个前端文件（实际是 4 HTML 在 `src/data/`），HTML/JS/CSS 内联积累技术债
4. **测试文件位置不规范**：24 个测试全在 `src/tests/`，无顶层 `tests/` 目录，pytest 自动发现依赖手动配置
5. **工作流缺设计**：112 个优先级做完了"能力"，但没有为"怎么用"设计流程

## 六、后续开发路线建议
