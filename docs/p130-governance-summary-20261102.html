二、阶段 5 · 领域专家复核修复详情

2.5.1 根因分析

专家复核确认 TOP FAIL 中的 DIM-006 16 条 + DIM-113 4 条 + EVAC-001 ROOM_636 1 条 共 21 条均为误报，归因两类根因：
根因涉及条目说明
疏散宽度聚合语义越界DIM-006 16 条（c157664）
DIM-113 4 条		GB50016-5.5.19/5.5.21 约束的是「防火分区疏散总净宽」，同一分区内多扇疏散门宽度应求和。逐门判定属于语义越界。
立面图门误识别DIM-006 中 15 条（c157664 立-门窗层）c157664 的 16 扇 DIM-006 门中 15 扇在 立-门窗 层、y≈1550~2050，不属于任何防火分区。立面图门不是平面图疏散门。
设备空间误判为疏散空间EVAC-001 ROOM_636（扫线法派生 3.28m² 小三角形）扫线法派生的 line_chain_* / 小面积 room 被 EVAC 函数判定为无疏散路径，实为非建筑空间或设备管井。

2.5.2 修复实现

修复项模块核心逻辑
WidthContext 统一聚合src/baa_engine/evac_width.py每个图纸构造一次，DIM-006/DIM-113 逐门判定前先查 aggregate_pass(entity, threshold)，分区求和后与阈值比较。三层回退：显式疏散门优先 → 全门兜底 → 无分区不聚合。
立面图门跳过同上无分区归属 + layer 含"立"或 y > 0 → 非平面疏散门，抑制判定。
疏散人数换算同上GB50016-5.5.21：所需总净宽 = 疏散人数/100 × 每百人指标，商店地上 0.65 / 3 层 0.75 / 4+ 层 1.00；地下 ≤10m 0.75 / >10m 1.00。无用途数据 → 回退「分区总宽 ≥ 单门阈值」。
设备空间识别增强classify.py + room_type_infer.py设备间/机房/配电间/管井/风井等关键词扩大 + 优先级前移至 anteroom 之前；增加 require_text 纯几何不足以判定设备空间，必须有文字证据。
EVAC 排除设备空间atomic_functions.pyEVAC-001/002/003/004 遇到 equipment_room / utility / elevator 或 layer="0" + area<10 的小房间直接返回 None。

三、阶段 6 · 图纸类型过滤修复详情

2.6.1 根因：classifier 空输入 + 权重策略泛化

阶段 5 后剩余 7 条 FAIL 全部来自 结构/暖通/电气专业图纸，但这些图纸 classifier 全判为 type='未知' conf=0.0。根因链：

  1. 文件名是 hash ID → 文件名关键词全失效
  2. self._doc.layers 在 DWG 下为空 → layer_names 为空列表
  3. primitives 的 entity.type 全是空字符串（实际类型在 dxf_type）→ 实体签名失效
  4. 即使 layer_names 有数据，"建筑"关键词里的 AXIS/DIM_/TEXT 是所有图纸都有的通用层，权重和"结构"专属关键词一样 → 建筑压过非建筑

2.6.2 修复实现

文件改动
drawing_parser.py从 primitives 收集 layer_names 和 dxf_type，替代空的 self._doc.layers / entity.type
drawing_classifier.py新增 _LAYER_PATTERN_HINTS（设计院自定义命名兜底）、_ENTITY_DOMINANCE_RULES、修正权重：结构/电气/暖通 1.5，建筑 0.5，通用层（AXIS/DIM/TEXT）不再给建筑加分
review_routes.py已有 is_non_arch 拦截 → 跳过审查（status="skipped"）
batch_routes.py新增 is_non_arch 拦截，返回 status="skipped" + error_code="NON_ARCHITECTURAL"
fp_rate_audit.py新增 skipped 路径，返回完整 dict 供审计脚本消费

新增两类根因：

⑧ 立面图误识别 — 无分区归属且图层/坐标属立面，被误当作平面疏散门（is_elevation_door 检测解决）
⑨ 扫线法派生非房间 — 结构/暖通图上扫线法把柱网/管道/说明框闭合也生成 room，被 EVAC 误判（图纸类型过滤解决）
⑩ classifier 空输入 — DWG hash ID 文件 classifier 返回"未知"，layer_names 空、entity.type 空（从 primitives 收集 + dxf_type 解决）
⑪ 权重泛化 — AXIS/DIM_/TEXT 通用层权重和非建筑关键词一样，在结构图上压过结构信号（非建筑权重 1.5 / 建筑 0.5 解决）
