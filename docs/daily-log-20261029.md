## 关键治理动作

### E6-T2 门宽阈值（此前 commit 已并入）
- 门宽 700→500mm：`500 <= length + 1 < 2000 and real_se < 50`，回收 533 条 door

### E6-T3 ARC/CIRCLE 微小半径
- `radius < 50 → other`（防装饰性弧线/圆误标为 window/column）
- ARC 门弧阈值放宽为 `50 <= radius < 2000`
- 修正 1193 条误分类（ARC 877 + CIRCLE 316）

### E6-T4 DWG 原生解析（根治 layer="0"，不留技术债）
- **根因链**：DXF 导出丢失图层语义 → LAYER_RULES 全失效 → 分类全靠几何兜底
- **方案**：`dwg_convert.py` 新增 `_try_ezdwg_direct` 作为第 0 级，`_parse_dwg` 对 `.dwg` 优先 ezdwg 直读，保留 `layer_handle → layer_name` 映射；失败自动降级原有 7 级兜底
- **效果**：51 个非零图层，layer="0" 从 100% 降至 10.1%
- **短 LINE 根因**：<500mm 中 ~5,599 条为 hatch（Y 聚类 ≥8 条/5mm）、~4,550 条为标注，归 other 正确，非分类缺陷
