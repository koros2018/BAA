## 1. 背景与根因

`_suppress_implausible_rooms` 原有 A/B/C/D/E/F/G 门禁分别处理退化多边形、未闭合边界、
重复实体、容器房间、空壳面、贴图框等几何异常。对于**同质周期性栅格**（看台座位格、
货架格、图例表格单元），每个成员单独过各门禁时均无明显异常——面积在合理范围、
无门洞邻接、无文字标注——因此全部通过，产出一堆无建筑语义的假房间。

**Stadion 案例**：P121-V 视图级过滤已将非平面子区整体判为非 plan 并跳过，但 y∈[33k, 37k]
的看台踏步区仍被判为 plan（有足够平面证据），扫线法在此区域内切出 11 个
4000×3100mm 同质矩形，全部进入审查清单。

### 1.1 门洞邻接判据的两个 Bug

初次实现使用单轴 AABB 投影重叠 (`ox > 50 OR oy > 50`) 判定门洞邻接：
- Stadion 看台格间 y≈33644，远处出口门 y≈62133，纵向距离约 25m；
  但横向有重叠 → 误判为「有门洞邻接」→ 该格间被保留（应去除）。
- 修复方案：**双轴实质重叠**才判定邻接：`ox > w/2 AND oy > h/2`，确保门洞与房间在两个方向上均有实质性交叉。

同时修正了初始化 bug：`candidates` 列表未声明导致 NameError（直调成功但集成失败）。

## 2. 结构判据设计

新增函数 `_detect_grid_pattern_suppressions()`，位于 [room.py L1802-L1962](file:///d:/OpenClawData/BAA/src/baa_engine/semantic_analyzer/room.py#L1802-L1962)。

### 2.1 触发条件

仅针对 **sweep 派生** 的房间实体（`line_chain_*` ID 前缀），显式分类的闭合多段线房间不参与检测。

### 2.2 六重检验（按成本升序）

| # | 检验 | 阈值 | 说明 |
|---|------|------|------|
| 1 | 面积 | ≤ 50㎡ | 超过则视为真实大空间而非格间 |
| 2 | 维度有效性 | w>0 && h>0 | 排除退化条目 |
| 3 | 门洞邻接 | 双轴实质重叠 (ox>w/2 && oy>h/2) | 排除有入口的真实标准间 |
| 4 | 文字标注 | 质心半径 2.5m 内有 TEXT | 排除带房间名的真实区域 |
| 5 | 尺寸桶分组 | round(w/100)\*100, round(h/100)\*100 | 同桶 ≥3 个才进下一步 |
| 6 | 同质 + 等距排列 | 宽高容差 <5%，间距 CV <0.5 | 区分真实标准间（尺寸可变）与纯格间（严格一致） |

满足全部条件 → 组内所有成员标记 `reasons=["grid_pattern"]`。

### 2.3 常量定义

```python
_GRID_MIN_COUNT = 3        # 同组最少实体数
_GRID_DIM_TOL = 0.05       # 宽高各自容差（5%）
_GRID_SPACING_CV = 0.50    # 间距变异系数上限
_GRID_AREA_MAX_M2 = 50.0   # 单格面积上限（㎡）
```

**不调阈值凑数**。当前值经五图验证后确认合适，如需调整须重新跑全量审计。
