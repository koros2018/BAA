一、阶段概览

本阶段围绕房间识别管线（扫线法平面图面遍历）做系统性性能优化， 从初始基线 10.2s 降至 3.09s（-70%）。 所有优化均保持功能严格等价（五图房间数不变）， 每个优化独立提交，代码与文档分开提交。

核心思路：空间网格索引（`_SpatialGrid`）从 O(n²) 全量扫描降为 O(n·k)， 再通过嵌套 dict、行内二分、快速拒绝、空间索引等 10 项增量优化逐层消除热点。

四、关键优化原理

1. 空间网格索引（_SpatialGrid）

`_split_t_junctions` 和 `_build_planar_graph` 原为 O(n²) 全量两两比较。 用 `_SpatialGrid`（cell_size=100mm）DDA 网格遍历，降为 O(n·k)。 dongguan 2791 段：`_split_t_junctions` 7.65s→1.79s，`_build_planar_graph` 21.48s→0.12s。

2. 嵌套 dict + 行内二分

`query_bbox` 遍历 135 万 cell 中 73% 为空。改嵌套 dict `cells[kx][ky]` 跳过空行， 再行内二分只遍历 ky 范围内存在键（非空 row 内 72.7% 空 cell）。 query_bbox 1.66s→0.30s（-82%）。

3. 快速拒绝 + 空间索引

E 空壳轮廓判定对每个大空间遍历全部 openings（dongguan 10 大空间 × 11169 openings）。 用 bbox 快速拒绝（点到 bbox 距离 > 5m 跳过）+ opening 空间网格索引， 只查询大空间附近的 openings。`_point_bbox_distance_mm` 从 profile 前 30 名消失。

4. 面积预过滤

C 重复实体判定 `_bbox_iou` 63088 次。利用 IoU > 0.90 ⟹ max/min < 1.111， 面积差更大时 IoU 必不达标，跳过精确计算。`_bbox_iou` 从 profile 前 30 名消失。

八、追加优化（2026-11-10 晚）：回折门洞判据 + 共线合并

8.1 回折修复门洞判据空间网格化

`_fold_spike_covered_by_door` 原实现遍历全部 doors（O(n·m)，65 次调用 × 全部门实体， dongguan 0.415s）。新增 door_grid（门 bbox 对角线插入），只查询尖刺 bbox 扩张 1mm 内的 候选门，从 profile 前 30 名消失。五图房间数严格等价。

8.2 共线区间合并排序+二分

`_merge_collinear` 原实现 coord_list 线性扫描找"第一个匹配簇"（O(n²)，dongguan 0.209s）。 保持"第一个插入簇"语义，用 sorted_anchors 二分找 anchor ∈ [coord-tol, coord+tol] 的候选 取 idx 最小者（严格等价）。实测 5000 组随机 + 4 张真实图纸 0 差异，从 profile 前 30 名消失。
